# Emotion-Aware Contrastive Learning for Zero-Shot Cross-Lingual Politeness Identification in Dialogues

This repository contains the dataset and code for our paper titled [XeroPol: Emotion-Aware Contrastive Learning for Zero-Shot Cross-Lingual Politeness Identification in Dialogues](https://ieeexplore.ieee.org/abstract/document/10601659/)

## Code
The folder Code/XeroPol contains the code for the proposed architecture.

## Data
The folder Data/ contains the datasets used in this work.
